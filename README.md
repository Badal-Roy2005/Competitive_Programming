# Competitive Programming Lab — Practical Codes

Welcome to the **Competitive Programming Lab** repository! 🚀

This repository is created for students to **upload, share, and access practical codes** completed during the Competitive Programming Lab.

The goal is to keep all lab practical programs organized in one place so that students can easily refer to previous implementations and practice them.

---

## 📌 What This Repository Contains

This repository contains:

* 💻 Competitive Programming Lab practical codes
* 🧩 Problem-solving implementations
* 📚 Algorithms and data structures covered in the lab
* 📝 Solutions to assigned practical problems
* 🤝 Contributions from students

## 🧑‍💻 How to Upload Your Code

### 1. Clone the Repository

```bash
git clone <repository-url>
```

### 2. Move Into the Repository

```bash
cd Competitive-Programming-Lab
```

### 3. Create Your Practical Folder

Go to the appropriate practical folder and create a folder using your **name or university ID**.

Example:

```text
Practical-01/
└── Ankan-Mondal/
    ├── problem1.cpp
    ├── problem2.cpp
    └── problem3.cpp
```

### 4. Add Your Code

Make sure your code:

* Compiles successfully
* Is properly formatted
* Has meaningful variable and function names
* Contains only the required files
* Does not contain unnecessary build files

### 5. Commit Your Changes

```bash
git add .
git commit -m "Add Practical 01 codes - Ankan Mondal"
```

### 6. Push Your Changes

```bash
git push
```

## 📝 Coding Guidelines

Please follow these basic guidelines while uploading code:

1. Use **C++** unless another language is specifically required.
2. Use meaningful file names.
3. Keep each problem in a separate file.
4. Do not upload compiled files such as `.exe`, `.out`, etc.
5. Avoid uploading unnecessary files.
6. Make sure your code is readable and properly indented.
7. Add comments where the logic may not be immediately obvious.
8. Do not copy code without understanding it.
9. Test your program before pushing it to the repository.

---

## 📁 File Naming Convention

Use simple and descriptive names.

### ✅ Recommended

```text
binary_search.cpp
linear_search.cpp
bubble_sort.cpp
merge_sort.cpp
two_sum.cpp
factorial.cpp
```

### ❌ Avoid

```text
code1.cpp
final.cpp
finalfinal.cpp
new.cpp
abc.cpp
test.cpp
```
